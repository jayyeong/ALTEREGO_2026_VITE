# KUAD 2026 · ALTER EGO

**건국대학교 의상디자인학과 2026 졸업전시 웹사이트**

일곱 팀의 작품과 참여 디자이너의 포트폴리오, 룩북, 런웨이 영상을 한곳에서 감상할 수 있는 온라인 전시 공간입니다. 전시의 준비 과정부터 이전 연도의 기록까지 담아, 전시가 끝난 뒤에도 작품과 이야기를 이어서 살펴볼 수 있도록 만들었습니다.

이 저장소에는 React 기반 프론트엔드와 배포 설정이 포함되어 있습니다.

## 사이트 소개

**ALTER EGO**는 타인의 시선과 비교에서 벗어나, 외면해 왔던 자신의 모습을 마주하는 데서 출발합니다. 각 팀은 이 주제를 서로 다른 시각으로 풀어내고, 의상과 이미지, 영상으로 자신만의 이야기를 전합니다.

참여 팀: **Limbo · (Un)skinned · Dreamscape · Tiny Lodge · 11:11 · 가시:화(花) · RE:I**

### 주요 기능

| 메뉴 | 소개 |
| --- | --- |
| **HOME · INFO** | 전시의 주제와 영상, 쇼 정보 |
| **PROJECT** | 일곱 팀의 콘셉트와 작품, 참여 디자이너의 포트폴리오 |
| **IMAGE** | 룩북과 런웨이 사진을 모은 갤러리 |
| **BEHIND** | 전시를 준비한 사람들과 무대 뒤의 과정을 담은 영상·사진 |
| **ARCHIVE** | 2024년과 2025년 전시로 이어지는 기록 |

런웨이와 비하인드 갤러리에서는 썸네일을 선택해 사진을 크게 볼 수 있습니다. 사이트는 데스크톱과 모바일에 맞춘 반응형 레이아웃을 제공합니다.

### 스토어 및 관리자

전시 굿즈 판매를 위한 상품 조회, 옵션 선택, 주문서 작성, 주문 완료 화면이 구현되어 있습니다. 현재 `main` 브랜치에서는 스토어와 주문 관련 페이지에 판매 종료 안내를 표시합니다.

관리자 화면에는 주문 조회, 입금 상태 변경, 상품 품절 관리, 기간별 엑셀 다운로드 기능이 있습니다. 관리자 기능을 사용하려면 별도 백엔드 API가 필요합니다. 서버와 데이터베이스 코드는 이 저장소에 포함되어 있지 않습니다.

## 개발 및 빌드

### 기술 스택

| 구분 | 기술 |
| --- | --- |
| UI | React 19, JavaScript, Tailwind CSS 3 |
| 라우팅 | React Router 7 |
| API 통신 | Axios |
| 개발 서버 및 빌드 | Vite 6 |
| 배포 | GitHub Actions, AWS S3, CloudFront |

런웨이 갤러리는 가벼운 썸네일을 먼저 표시하고, 사진을 크게 볼 때 원본 이미지를 불러와 초기 로딩 부담을 줄였습니다. 구현 과정은 [런웨이 최적화 PR #27](https://github.com/jayyeong/ALTEREGO_2026_VITE/pull/27)에서 확인할 수 있습니다.

### 설치 및 실행

Node.js 20과 npm을 사용합니다. 저장소를 내려받은 뒤 의존성을 설치하고 개발 서버를 실행합니다.

```bash
git clone https://github.com/jayyeong/ALTEREGO_2026_VITE.git
cd ALTEREGO_2026_VITE
npm ci
npm run dev
```

기본 접속 주소는 [http://localhost:5173/2026/](http://localhost:5173/2026/)입니다. 해당 포트가 사용 중이면 터미널에 표시된 주소로 접속합니다.

전시 이미지와 영상은 `public/`에 있습니다. 저장소를 일부만 내려받는 sparse checkout을 사용한다면 이 폴더도 포함해야 합니다.

### 환경 설정

개발 서버에만 적용할 값은 `.env.development.local`에, 배포용 빌드에 적용할 값은 `.env.production.local`에 설정합니다.

```env
VITE_API_URL=
VITE_STORE_ONLY_MODE=false
```

| 변수 | 설명 |
| --- | --- |
| `VITE_API_URL` | 백엔드 API의 기본 주소입니다. 비워 두면 현재 접속한 사이트와 같은 주소로 API를 요청합니다. |
| `VITE_STORE_ONLY_MODE` | 배포용 빌드에서 값이 `true`이면 전시 페이지 접근을 제한합니다. 개발 서버에는 적용되지 않습니다. |

API 기능을 사용하려면 별도 백엔드 연결이 필요합니다. `VITE_` 환경 변수는 브라우저에 공개되므로 비밀 키를 넣지 않습니다.

공개 모드는 전시 페이지의 표시 여부를 제어하며, 브라우저에 저장된 공개 설정에 따라 제한이 해제될 수 있습니다. 서버의 접근 권한을 보호하는 인증 기능은 아닙니다. 스토어와 주문 페이지는 별도 라우트 설정에 따라 종료 안내를 표시하므로, 이 값만 바꿔서는 다시 열리지 않습니다. 자세한 동작은 [라우트 설정](src/App.jsx)과 [공개 모드 설정](src/config/siteMode.js)을 참고하세요.

### 빌드 및 미리보기

```bash
npm run build
npm run preview
```

`npm run build`는 배포할 정적 파일을 `dist/`에 생성합니다. `npm run preview`는 빌드 결과를 로컬에서 확인하는 명령어입니다. 터미널에 표시된 주소의 `/2026/` 경로로 접속합니다.

현재 자동 테스트와 lint 스크립트는 없습니다. 빌드 성공 여부와 별개로 화면 표시와 API 연동은 직접 확인해야 합니다.

### 프로젝트 구조

```text
src/
  components/        헤더, 스크롤 처리 등 공통 UI
  config/            API 주소와 페이지 공개 설정
  data/              팀, 디자이너, 상품 관련 데이터
  pages/             전시, 스토어, 관리자 화면
  utils/             이미지 경로, 날짜 표시 등 공통 함수
public/              이미지와 영상 등 정적 리소스
docs/screenshots/    README에 사용하는 웹사이트 화면
.github/workflows/   배포 자동화 설정
```

## 배포

같은 도메인에서 연도별 전시를 운영하기 위해 `/2026/`을 기본 경로로 사용합니다. `main` 브랜치에 변경사항을 push하거나 워크플로를 수동 실행하면 다음 순서로 배포됩니다.

```text
의존성 설치 → Vite 빌드 → S3 업로드 → CloudFront 캐시 갱신
```

이미지·스크립트 등 정적 파일에는 장기 캐시를 적용하고, HTML·아이콘·manifest에는 변경된 내용을 확인하도록 별도 캐시 정책을 적용합니다. 자세한 설정은 [배포 워크플로](.github/workflows/deploy.yml)에서 확인할 수 있습니다. 현재는 README만 변경해도 `main`에 반영하면 자동 배포가 실행됩니다.
