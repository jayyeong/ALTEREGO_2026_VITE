# 운영 반영 전 디자인·기능 검증

2026-09-30. 현재 운영 커밋 `1a539b0dd9aa1bb4a862e886005c63d1e146f4d8`과 성능 개선 커밋을 별도 빌드해 비교했다. 기존 빌드의 JavaScript 파일 이름은 운영 사이트의 `index-C0_jdLpS.js`와 일치했다. 기존 작업 폴더의 스토어·라우팅 변경은 포함하지 않았다.

## 발견한 문제와 수정

데스크톱 포트폴리오에서 `sizes="40vw"`가 `width:auto` 이미지의 밀도 보정된 고유 너비를 실제 컨테이너보다 작게 만들어 작품 이미지가 줄어드는 것을 발견했다. 1440px 화면에서 616px이던 이미지가 576px로 표시됐다. 각 반응형 구간의 기존 최대 폭인 280·560·680px을 `sizes`에 반영해 원래 레이아웃을 복원했다. 모바일의 표시 폭은 유지했다.

모바일 한 화면에서 감지됐던 높이 차이는 지연 로딩 이미지가 표시되기 전 비교를 끝낸 검사 문제였다. 이미지 디코딩 완료 후 비교하도록 보완했고 기존·개선 버전 모두 3108px의 같은 높이를 확인했다.

## 최종 검증

- 공개 74개 경로 × 412·768·1440px = 222건 전후 비교.
- 대표 8개 경로 × 375·1024·1920px = 24건 추가 비교.
- 총 246건에서 텍스트, 요소 수, 글꼴·색상 등 비교한 계산 스타일 차이 없음. 좌표·크기는 0.75 CSS px 허용오차 내 일치. 깨진 이미지, 가로 넘침, JavaScript 오류 없음.
- 전시 정보·포트폴리오·룩북의 전후 스크린샷을 육안으로 대조했다. 이미지 재인코딩 결과의 픽셀 동일성을 주장하는 검사는 아니다.
- 홈 영상 8개 × 모바일·데스크톱: 재생·다음 전환 정상, 이전 전환도 확인. 모바일은 720p 이하, 데스크톱은 원본을 사용한다.
- 비하인드·런웨이 갤러리 × 모바일·데스크톱: 마지막 이미지에서 첫 이미지로 이동, 이전 복귀, Escape 닫기와 스크롤 복구 확인. 확대 화면은 원본 사용.
- 룩북 목차 7개 모두 목표 여백 8px에서 1px 이내에 도착하고 이미지 로딩 확인.
- 모바일 메뉴 INFO 이동, 스토어 종료 화면 6개 경로, 기존 리다이렉트 4개 확인. 기능 검사 중 사이트 자체 리소스 HTTP 오류 없음.
- 잠금 파일로 `npm ci` 후 930개 이미지 파생본을 처음부터 생성하는 프로덕션 빌드 성공. 수정 후 재빌드 성공.

기존 120회 Lighthouse 측정은 최초 최적화 작업 빌드의 기록이다. 최종 배포 후보는 스토어 변경 제외와 위 이미지 크기 보정 때문에 별도 빌드 식별자를 가진다. 초기 측정 빌드와 최종 배포 후보의 해시가 같다고 해석하지 않는다. 로컬 검증이며 운영 배포 후 점검은 별도로 필요하다.

현재 원격 업로드는 자동 승인 검토에서 공개 저장소·브랜치·파일 범위에 대한 명시적 승인 필요로 차단되어 있다. PR·운영 배포는 수행하지 않았다.
